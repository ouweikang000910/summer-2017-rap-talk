# 回到2017

中国有嘻哈主题演讲网页：霓虹字体、17页翻页演讲、柔和转场与15题猜歌互动。

**在线访问：[打开演讲网页](https://ouweikang000910.github.io/summer-2017-rap-talk/)**

## 使用

使用底部上一页/下一页、方向键、PageUp/PageDown或空格翻页。滚轮每次切换一页，手机支持左右滑动。顶部导航和目录可直接跳转。手机或小窗口中，较长的一页可在页内上下浏览。

- `F`：全屏
- `O`：目录
- `R`：揭晓当前猜歌题
- `B`：黑屏暂停，`Esc` 返回
- `Home` / `End`：首页 / 末页
- `Shift` + 空格：上一页

猜歌游戏共15题，支持15秒计时、隐藏/揭晓答案和A/B两组计分。使用游戏里的“上一题/下一题”切换题目，底部“上一页/下一页”切换演讲页。离开猜歌页自动停止播放；翻回来时保留当前题目、答案状态、导入的音乐和比分。

网页不内置歌曲音频。点击“音乐准备”逐首或批量导入本地音乐，按文件名中的歌名自动匹配。可设置片段开始位置，每题播放15秒。导入的音频只在当前页面会话中使用，不上传，刷新后需要重新导入。也可使用外部播放器，配合网页计时。

每题设有“打开歌曲”链接，指向对应版本的网易云音乐歌曲页；“音乐准备”中可查看完整15首歌的链接，也提供 QQ音乐搜索入口。链接在新标签页打开，未揭晓时游戏区不显示歌名。第13题使用正式歌名《别怕变老》（导入时也匹配“不怕变老”）；第12题使用顽童MJ116的《迷途羔羊》现场版。第7题使用正式歌名《大展鸿图》（也匹配“大展宏图”）。

## 修改与部署

纯静态网页，无构建依赖。直接打开 `index.html` 即可离线浏览。

- `data.js`：题目、歌手、代表作与歌曲链接
- `app.js`：页面和互动逻辑
- `style.css`：字体、配色与动效
- `deck.js` / `deck.css`：翻页控制、手势、转场与逐页排版
- `assets/`：图片、字体及字体许可证
- `来源说明.txt`：资料与图片来源

GitHub Pages 从 `main` 分支根目录发布；提交更新后自动重新部署。
