# 回到2017

中国有嘻哈主题演讲网页：霓虹字体、连续上下滚动、滚动入场动效与15题猜歌互动。

**在线访问：[打开演讲网页](https://ouweikang000910.github.io/summer-2017-rap-talk/)**

## 使用

使用滚轮或触控板上下浏览，顶部导航可跳转章节。

- `F`：全屏
- `N`：讲稿提示
- `O`：目录
- `R`：揭晓当前猜歌题
- `B`：黑屏暂停，`Esc` 返回

猜歌游戏共15题，支持15秒计时、隐藏/揭晓答案和A/B两组计分。

网页不内置歌曲音频。点击“音乐准备”逐首或批量导入本地音乐，按文件名中的歌名自动匹配。可设置片段开始位置，每题播放15秒。导入的音频只在当前页面会话中使用，不上传，刷新后需要重新导入。也可使用外部播放器，配合网页计时。

## 修改与部署

纯静态网页，无构建依赖。直接打开 `index.html` 即可离线浏览。

- `data.js`：题目、歌手与讲稿
- `app.js`：页面和互动逻辑
- `style.css`：字体、配色与动效
- `assets/`：图片、字体及字体许可证
- `来源说明.txt`：资料与图片来源

GitHub Pages 从 `main` 分支根目录发布；提交更新后自动重新部署。
