# 回到2017

中国有嘻哈主题演讲网页：霓虹字体、17页翻页演讲、柔和转场与15题猜歌互动。

**在线访问：[打开演讲网页](https://ouweikang000910.github.io/summer-2017-rap-talk/)**

## 使用

使用底部上一页/下一页、方向键、PageUp/PageDown或空格翻页。滚轮每次切换一页，手机支持左右滑动。顶部导航和目录可直接跳转。手机或小窗口中，较长的一页可在页内上下浏览。

- `F`：全屏
- `O`：目录
- `R`：揭晓当前猜歌题
- `B`：黑屏暂停，`Esc` 返回
- `Home` / `End`：首页 / 末页
- `Shift` + 空格：上一页

猜歌游戏共15题，支持隐藏/揭晓答案和 A/B 两组计分。点击“开始播放”直接在当前网页播放音频，支持暂停/继续、拖动进度和从设定起点重新播放。没有倒计时，也不会在15秒后停止。换题、揭晓答案或离开猜歌页会停止播放。

点击“音乐准备”，选择 MP3、M4A、FLAC、WAV 等普通音频，可批量选择文件或文件夹，按文件名中的歌名自动匹配。每首可指定播放起点。音频通过 IndexedDB 保存在当前设备的同一个浏览器中，刷新后自动恢复，不上传到 GitHub；更换设备、换浏览器、使用无痕模式或清除网站数据后可能需要重新选择。存储不可用或空间不足时明确提示，只使用当前会话。

网页没有内置15首歌曲音频，未准备时会明确显示状态，点击播放会打开音乐准备。网易云会员歌曲下载可能为 NCM 加密格式，浏览器不能播放该格式；当前页面不接入网易云账号、不转换加密文件。文件选择允许识别 NCM，但会明确提示无法播放，不会计为已准备歌曲。猜歌区和音乐准备没有跳转到外部音乐网站的入口。

第13题使用正式歌名《别怕变老》（也匹配“不怕变老”）；第12题使用顽童 MJ116 的《迷途羔羊》现场版；第7题使用正式歌名《大展鸿图》（也匹配“大展宏图”）。

GAI、Jony J、欧阳靖、Tizzy T分别以纯文字列出5首代表作，不再点击跳转听歌，第4位人物改为艾福杰尼，含2017年舞台照片、《After Journey》《库尔勒》《说散就散》三首代表作；第15页改为“说唱走进生活”。


人物介绍页配有官方歌曲试听：进入人物页自动尝试播放对应歌手的试听片段，换人时换歌，离开人物页立即停止。首次受浏览器自动播放限制时，点击一次“开启声音”，后续正常翻页会自动播放。每页可关闭声音，选择会保存在此浏览器中。试听只在线串流，不下载或保存到猜歌音乐库；需要联网，片段结束后不会循环。

六页试听曲目：GAI《苦行僧 (Live)》、PG ONE《语音备忘录》、Jony J《不用去猜》、艾福杰尼《After Journey II (Live)》、欧阳靖《Learn Chinese》、Tizzy T《头文字T (Live)》。试听旁附 iTunes 歌曲入口与来源署名。

## 修改与部署

纯静态网页，无构建依赖。直接打开 `index.html` 即可离线浏览。

- `data.js`：题目、歌手、代表作与歌曲链接
- `app.js`：页面、互动与音频播放逻辑
- `audio-library.js`：本地浏览器音乐保存
- `artist-audio.js`：人物页自动试听与声音开关
- `style.css`：字体、配色与动效
- `deck.js` / `deck.css`：翻页控制、手势、转场与逐页排版
- `assets/`：图片、字体及字体许可证
- `来源说明.txt`：资料与图片来源

GitHub Pages 从 `main` 分支根目录发布；提交更新后自动重新部署。
