# 回到2017

中国有嘻哈主题演讲网页：霓虹字体、17页翻页演讲、柔和转场与15题猜歌互动。

**在线访问：[打开演讲网页](https://ouweikang000910.github.io/summer-2017-rap-talk/)**

## 使用

使用底部上一页/下一页、方向键、PageUp/PageDown或空格翻页。滚轮每次切换一页，手机支持左右滑动。顶部导航和目录可直接跳转。手机或小窗口中，较长的一页可在页内上下浏览。

- `F`：全屏
- `O`：目录
- `R`：揭晓当前猜歌题
- `B`：黑屏暂停，`Esc` 返回
- `Home` / `End`：首页 / 末页
- `Shift` + 空格：上一页

猜歌游戏共15题，不分组、不计分。点击“开始播放”在当前网页播放，没有倒计时。12题使用在线音频，3题打开网页内的官方视频播放器（第8、10、12题），不会另开音乐网站。换题、揭晓答案或离开猜歌页会停止音频；关闭视频弹层会停止视频。视频需要能访问 YouTube，播放器可能显示歌名、歌手和现场画面。

12首音频已逐首配置：网易云音乐公开串流11首，王以太参与的《一人之境》作品推荐节目节选1首。《阿司匹林》使用30秒节目片段，到时停止，可重新播放；其他音频支持暂停、继续、拖动进度和重播。在线音源会受平台及网络可用性影响，不下载完整歌曲、不打包进仓库。

版本区别：《恭喜发财》《别怕变老》使用对应原唱现场版；《危险派对》使用刘至佳独唱现场版，原版艺人为王以太/刘至佳；《星球坠落》为艾热/李佳隆2022现场视频；《迷途羔羊》为兄弟本色（包括顽童MJ116、张震岳等）的官方MV。歌曲顺序保持用户指定的15首，第7题采用正式歌名《大展鸿图》，第13题为《别怕变老》。音源来源及版本在揭晓后和音乐准备中说明。

点击“音乐准备”可逐首替换为本地 MP3、M4A、FLAC、WAV 等普通音频，也支持按歌名批量匹配。导入文件通过 IndexedDB 保存在当前设备的浏览器中，刷新后恢复，不上传到 GitHub；移除本地文件后恢复该题的在线音源。NCM等加密文件不能在浏览器播放，不会导入或计为可播放音频。

六位人物依次为 GAI、Bridge 布瑞吉、Jony J、艾福杰尼、李大奔 BENZO、Tizzy T。代表作以纯文字展示，第15页为“说唱走进生活”。进入人物页自动尝试播放对应歌曲，换人时换歌，离开人物页停止。首次受浏览器自动播放限制时，点击一次“开启声音”，后续正常翻页会自动播放。声音开关保存在此浏览器中，片段结束后不循环。

六页曲目：GAI《苦行僧 (Live)》、Bridge《老大》（《音乐灵感》嘉宾本人选曲节目30秒节选）、Jony J《不用去猜》、艾福杰尼《After Journey II (Live)》、李大奔《江南少爷 (Live)》、Tizzy T《头文字T (Live)》。除Bridge节目节选外，人物页均使用 iTunes 官方宣传试听，附歌曲入口与来源署名，未用于猜歌游戏。

Bridge 照片来自 NOWRE 现客2019年专访；李大奔采用浙江在线2017年的本人舞台照片。图片来源在人物页及来源说明中注明。

## 修改与部署

纯静态网页，无构建依赖。可用静态服务器浏览；在线歌曲和视频需要联网。

- `data.js`：题目、歌手、代表作与歌曲链接
- `app.js`：页面、互动与音频播放逻辑
- `audio-library.js`：本地浏览器音乐保存
- `artist-audio.js`：人物页自动试听与声音开关
- `style.css`：字体、配色与动效
- `deck.js` / `deck.css`：翻页控制、手势、转场与逐页排版
- `assets/`：图片、字体及字体许可证
- `来源说明.txt`：资料与图片来源

GitHub Pages 从 `main` 分支根目录发布；提交更新后自动重新部署。
