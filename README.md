# 回到2017

中国有嘻哈主题演讲网页：霓虹字体、16页翻页演讲、柔和转场与15题猜歌互动。

**在线访问：[打开演讲网页](https://ouweikang000910.github.io/summer-2017-rap-talk/)**

## 使用

使用底部上一页/下一页、方向键、PageUp/PageDown或空格翻页。滚轮每次切换一页，手机支持左右滑动。顶部导航和目录可直接跳转。手机或小窗口中，较长的一页可在页内上下浏览。

- `F`：全屏
- `O`：目录
- `R`：揭晓当前猜歌题
- `B`：黑屏暂停，`Esc` 返回
- `Home` / `End`：首页 / 末页
- `Shift` + 空格：上一页

猜歌游戏共15题，不分组、不计分，全部使用纯音频。点击“开始播放”直接在当前页面播放，支持暂停、继续、拖动进度和重播。没有视频弹窗或外部跳转。换题、揭晓答案或离开猜歌页会停止播放。

15题包含10首网易云音乐公开串流、5段音乐节目中的原唱歌曲节选（第1、8、9、10、12题，各30秒）。节目节选到时停止，可反复播放，不会继续播放主持人对话。音源均需联网，不下载完整歌曲、不打包进仓库。

## 修改与部署

纯静态网页，无构建依赖。可用静态服务器浏览；在线音频需要联网。

- `data.js`：题目、歌手、代表作与歌曲链接
- `app.js`：页面、互动与音频播放逻辑
- `audio-library.js`：本地浏览器音乐保存
- `artist-audio.js`：人物页自动试听与声音开关
- `style.css`：字体、配色与动效
- `deck.js` / `deck.css`：翻页控制、手势、转场与逐页排版
- `assets/`：图片、字体及字体许可证
- `来源说明.txt`：资料与图片来源

GitHub Pages 从 `main` 分支根目录发布；提交更新后自动重新部署。
